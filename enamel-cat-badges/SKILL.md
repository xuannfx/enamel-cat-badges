# 珐琅猫咪徽章

将猫与主题的自然互动做成可收藏的珐琅徽章。先读取[设计体系](references/design-system.md)，按本次任务完成策划、提示词、生成或导出。

1. 先执行下方需求确认，再用[策划单](assets/series-brief.md)落实猫、主题锚点、接触动作和构图。二十四节气整套先比较全年主题差异。
2. 在[素材索引](references/materials.md)中选取相关正面，实际查看后用于风格参考。角色、核心动作与主题配饰一起决定构图。
3. 编写或执行生图任务时读取[提示词与示例](references/prompts.md)，把本次策划展开成完整描述，并传入选择的实际参考图。使用当前可用的图像生成工具及其规定流程；入口不可用时交付提示词和参考路径，准确报告未生成。
4. 新版本或明显改变细节方向时，读取[版本设计与生成](references/versions.md)，先重做物件清单、构图与线宽方案，再提交该版本的完整说明。
5. 合图先评审肢体、接触、角色一致性与配饰递进，再导出透明正面，按设计体系检查真实Alpha、目标展示尺度与所选细节丰富度。

正面和背面材质分阶段处理。正面方案确认后，主动向用户说明匹配的背面材质方案与生成／复用选项，等待确认后再生成或采用；具体流程见设计体系的“背面与材质”。最终报告实际交付文件、数量、源图和检查结果。

## 开始设计前的需求确认

从用户当前消息和已确认上下文提取以下四项，只询问缺失或含糊的项目，集中一轮提问，等待回答后再进入具体策划、完整生图提示词或生成：

- 主题：哪个节日、节气、行为或纪念主题？“节日徽章”仍需确定具体主题。
- 材质：金属基底／外观是什么，采用什么表面处理与工艺？可选银色金属加珐琅，也可用纯金属或其他材质。明确选择非金属即已回答，不再强求金属。
- 是否分级：单枚、无等级的多款，还是有等级的系列？需要等级时再确认级数；名称、材质是否变化等按实际需要补充。
- 细节意图：装饰物丰富、工艺精细，还是两者兼有？可用“基础、丰富、精工”等自然语言回答，再按设计体系展开为装饰物、构图层次、表面纹饰、工艺精度四项；不把它们当作单轴高低档。

提问示例：“想做哪个主题？材质想用银色珐琅、纯金属还是其他？做单枚／平行多款／分级系列？细节想要少物件简洁、多装饰物的完整场景、少物件但精工，还是两者兼有？”实际提问删去用户已经说清的部分。用户可用自然语言回答，不要求填写表单。

用户明确说“你来定”或授权某些选项自主发挥时，记录其授权范围并提出具体选择，不重复追问这些项。仅询问用法或讨论材料可能性时，直接讨论，无需启动设计问卷。现有参考代表基础版本；继承哪些造型或工艺、提高哪些细节，要在提示词中分别说明。
